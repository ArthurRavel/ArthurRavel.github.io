# Ravel OS

Le portfolio d'Arthur Ravel, présenté comme un petit système d'exploitation : démarrage, écran de chargement, puis un terminal dont les commandes s'exécutent au défilement.

- Une seule page statique (`index.html`), sans étape de build.
- Le démarrage ne se joue qu'une fois par session ; `?boot` le relance, et la commande `reboot` aussi.
- Les animations sont coupées si le système demande moins de mouvement.
- L'ancien site est conservé dans `ancien/`.
